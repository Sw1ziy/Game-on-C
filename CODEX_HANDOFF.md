# BATFLIP — где остановились

Обновлено 21.11.2026.

Это игра на C и ncurses для [задания PS4](https://kurzy.kpi.fei.tuke.sk/zap/problemsets/ps-04.html). План игры — три уровня. На каждом летучая мышь собирает заданное число мотыльков, чтобы открыть выход.

## Как продолжать работу

Общаемся по-русски. Пользователь пишет игровой код сам. Codex смотрит попытки, объясняет ошибки и даёт по одной подсказке за раз. Готовый код в файлы вносим по прямой просьбе пользователя. Перед удалением файлов, включая `make clean`, спрашиваем разрешение.

На другом ПК открой актуальный `game.c` и сверь `git status` перед правками. Для разработки в Windows уже используется MSYS2 UCRT64. В папке игры команда `make run` собирает и запускает её. На учебном Linux файл для сдачи должен называться `ps4/program.c`. Если ты уже находишься внутри `ps4`, команда проверки такая:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -Werror program.c -o betflip -lcurses && ./betflip
```

## Что уже сделано

- Заставка с логотипом BATFLIP, полосой загрузки и надписью START. После заставки открывается комната с рамкой.
- Пользователь добавил автоматический полёт после пробела и написал `GameInput` с полями `move_key`, `flip_key`, `reset` и `quit`. Функция `read_input_key()` читает очередь ncurses до `ERR` и сохраняет команды по отдельности.
- A/D и стрелки двигают мышонка. Пробел переворачивает гравитацию у пола или потолка. В полёте можно менять направление по горизонтали. R возвращает мышонка в левый нижний угол. Q или Esc завершает игру.
- Настройку ввода вынесли в `setup_controls()`, отрисовку кадра — в `draw_game()`. В последней рисуется один неподвижный мотылёк `*`, строка `1`, столбец `COLS / 2`. Если мышонок попадёт в эту клетку, он перекроет звёздочку, но ещё не соберёт её.

## Следующая задача

Добавить сбор одного мотылька. Хранить его координаты и флаг сбора, проверять совпадение координат после движения, рисовать мотылька только пока он не собран. Клавиша R должна возвращать и мышонка, и мотылька. Счётчик, выход и отдельные уровни пока в плане.

Проблема с удержанием направления во время переворота отложена. Обычный ввод ncurses может сделать паузу по горизонтали после пробела, даже если A или D ещё зажата. Проба с событиями отпускания клавиш работала через SSH на `zap2`. Пробный код откатили, чтобы пользователь мог написать свой вариант по шагам. В браузерном терминале университета этот режим пока не проверяли.
