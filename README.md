# Game-on-C

Платформер на языке C с тремя уровнями.

> 🚧 Проект в разработке: идея и план могут меняться.

## Задумка

- Игра работает прямо в терминале, графика из ASCII-символов (библиотека **ncurses**).
- Три уровня, каждый сложнее предыдущего.
- Уровни хранятся в обычных текстовых файлах, поэтому новый уровень можно нарисовать в любом редакторе:

  ```
  ############################
  #   @        ===      $    #
  #  ===   ==        ======  #
  ############################
  ```

  `@` игрок, `=` платформа, `$` выход, `#` стена.

## Что планируется

- [ ] Движение игрока, гравитация и прыжки
- [ ] Загрузка уровней из файлов
- [ ] Три уровня
- [ ] Меню
- [ ] Цвета
- [ ] Таймер прохождения

## Сборка

Нужны `gcc` и `ncurses`. Инструкция появится, когда игра начнёт собираться.
